# 8pt MCP config examples

Replace `<YOUR_8PT_API_KEY>` with a key from 8pt.dev → Settings → API Key. Never commit real keys.

- `claude-code.sh` — Claude Code
- `cursor-mcp.json` — Cursor (`~/.cursor/mcp.json`)
- `codex-config.toml` — Codex (`~/.codex/config.toml`)
- `trae-mcp.json` — Trae (Settings → MCP → Add manually)
